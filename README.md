# Shopify Sales Analysis

An end-to-end sales and customer behavior analysis of one week of Shopify transaction data (Mar 18–24, 2025), covering **7,420 orders** from **4,425 customers**. Built as a Power BI project, with an accompanying interactive HTML dashboard preview and written report.

Prepared by Sree Akanksha Munduri.

## 📁 Files in this repo

| File | Description |
|---|---|
| `Shopify_Sales_Cleaned.xlsx` | Cleaned, analysis-ready transaction dataset |
| `Shopify_Sales_Dashboard.html` | Interactive dashboard preview (open directly in any browser — no install needed) |
| `Shopify_Sales_Analysis_Report.docx` | Full written report with findings and recommendations |

## 📊 Key Metrics

- **Total Revenue:** $4.59M
- **Total Orders:** 7,420
- **Average Order Value:** $618.85
- **Repeat Purchase Rate:** 46%
- **Revenue from Top 20% of Customers:** 37.8%

## 🔑 Key Insights

- Revenue grew 30% across the week ($577K → $751K), though not linearly — Friday and Sunday both dipped 15%+ before rebounding.
- **Running, Tennis, and Walking Shoes drive 71% of total revenue**, while 7 of 14 product categories each contribute under 2%.
- 46% of customers return within the same week, with a **median gap of just 43.6 hours** to a second order — a short, high-leverage retention window.
- Revenue concentration is moderate — the top 20% of customers generate 38% of revenue, indicating broad-based growth rather than dependence on a few high spenders.
- Order frequency drops sharply after the second purchase (1,322 customers reach 2 orders vs. only 36 reaching 5+), suggesting converting first-time buyers into repeat buyers matters more than deepening loyalty among existing repeat customers.
